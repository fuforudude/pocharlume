# Fagot d'Os (région 6, dessiné) : un fagot d'os longs et de côtes hérissés comme un hérisson, un crâne au sommet. Qui le frappe s'y blesse.
# 32×32, ancre aux pieds, de profil vers la droite. Version d'élite (`fagot-os-elite`) : même recette (`modele`), tout assombri (`sombre`),
# yeux rouges (le calque `yeux` est vide dans la version normale ; il suit la tête dans chaque cadre).
# Fichier généré une première fois par un script puis retouché à la main : on le modifie ici.
categorie ennemi
palette commune
taille 32 32
ancre 16 30

calque yeux
.

calque tete 13 5
..PPPP..
.PqqqqP.
.PkqqkP.
.PqqqqP.
..PkkP..
...PP...

calque corps 8 10
...q...w..q....
..qw.q.wq.w.q..
.q.qwqPqqwq.q..
..qwqPPqwqPq...
.wqPqwwPqPqwq..
..qPwqkkqwPq...
.q.qPqkkqPq.q..
..wqPqkkqPqw...
...qPPwwPPq....
....qPPPPq.....
....qkPPkq.....

calque jambes 12 21
.q..q..
.q..q..
.w..w..
.q..q..
.P..P..
qq..qq.
.......

calque jambes-a 12 21
.q...q.
.q...q.
w....w.
q....q.
P....P.
qq...qq
.......

calque jambes-b 12 21
..qqq..
..qqq..
..www..
..qPq..
..qPq..
.qq.qq.
.......

calque tas 8 24
..q..w..q.w...
.qwqPqwqPqwq..
qPqwqkPqwqPqq.
wqPqwPqwPqwPqw

sprite fagot-os
anim repos 220
cadre jambes + corps + tete + yeux
cadre jambes + corps decale 0 -1 + tete decale 0 -1 + yeux decale 0 -1

anim marche 110
cadre jambes-a + corps + tete + yeux
cadre jambes + corps decale 0 -1 + tete decale 1 -1 + yeux decale 1 -1
cadre jambes-b + corps + tete + yeux
cadre jambes + corps decale 0 -1 + tete decale -1 -1 + yeux decale -1 -1

# Il se jette en avant, tout hérissé.
anim attaque 100
cadre jambes + corps decale -1 0 + tete decale -2 0 + yeux decale -2 0 duree 170
cadre jambes-a + corps + tete decale 2 1 + yeux decale 2 1
cadre jambes-a + corps decale 1 0 + tete decale 3 1 + yeux decale 3 1 duree 140
cadre jambes + corps + tete + yeux

anim blesse 120
cadre jambes + corps decale -1 0 + tete decale -2 1 + yeux decale -2 1
cadre jambes + corps + tete decale -1 0 + yeux decale -1 0

# Il s'éboule en tas d'os.
anim mort 160
cadre jambes + corps decale -1 2 + tete decale -3 3 + yeux decale -3 3
cadre jambes-b decale 0 3 + corps decale 0 5 + tete decale -2 7 + yeux decale -2 7
cadre tas duree 900

sprite fagot-os-elite
modele fagot-os
sombre
calque yeux 14 7
x..x
