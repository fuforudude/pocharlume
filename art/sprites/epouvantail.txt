sprite epouvantail
anim repos 220
cadre jambes + corps + tete + yeux
cadre jambes + corps decale 0 -1 + tete decale 0 -1 + yeux decale 0 -1

anim marche 110
cadre jambes-a + corps + tete + yeux
cadre jambes + corps decale 0 -1 + tete decale 1 -1 + yeux decale 1 -1
cadre jambes-b + corps + tete + yeux
cadre jambes + corps decale 0 -1 + tete decale -1 -1 + yeux decale -1 -1

# Le bras de paille frappe en avant.
anim attaque 100
cadre jambes + corps decale -1 0 + tete decale -2 0 + yeux decale -2 0 duree 170
cadre jambes-a + corps-frappe + tete decale 2 1 + yeux decale 2 1
cadre jambes-a + corps-frappe decale 1 0 + tete decale 3 1 + yeux decale 3 1 duree 140
cadre jambes + corps + tete + yeux

anim blesse 120
cadre jambes + corps decale -1 0 + tete decale -2 1 + yeux decale -2 1
cadre jambes + corps + tete decale -1 0 + yeux decale -1 0

# Il s'affaisse sur ses jambes puis ne reste qu'un tas de paille et son chapeau.
anim mort 160
cadre jambes + corps decale -1 2 + tete decale -3 3 + yeux decale -3 3
cadre jambes-b decale 0 3 + corps decale 0 5 + tete decale -2 7 + yeux decale -2 7
cadre tas duree 900

# Le tas se rassemble : le mort revient (le rendu la joue quand l'épouvantail se relève).
anim releve 160 unique
cadre tas
cadre jambes-b decale 0 3 + corps decale 0 5 + tete decale -2 7 + yeux decale -2 7
cadre jambes + corps decale -1 2 + tete decale -3 3 + yeux decale -3 3

sprite epouvantail-elite
modele epouvantail
sombre
calque yeux 14 12
