# Gargouille (région 10, dessinée) : de la pierre grise, des ailes de chauve-souris, une gueule de cathédrale. Elle se fige en statue pour se rendre intouchable.
# 32×32, ancre aux pieds, de profil vers la droite. Version d'élite (`gargouille-elite`) : même recette (`modele`), tout assombri (`sombre`),
# yeux rouges (le calque `yeux` est vide dans la version normale ; il suit la tête dans chaque cadre).
# Fichier généré une première fois par un script puis retouché à la main : on le modifie ici.
categorie ennemi
palette commune
taille 32 32
ancre 16 30

calque yeux
.

sprite gargouille
anim repos 220
cadre jambes + fond + corps + tete + yeux
cadre jambes + fond decale 0 -1 + corps decale 0 -1 + tete decale 0 -1 + yeux decale 0 -1

anim marche 110
cadre jambes-a + fond + corps + tete + yeux
cadre jambes + fond decale 0 -1 + corps decale 0 -1 + tete decale 1 -1 + yeux decale 1 -1
cadre jambes-b + fond + corps + tete + yeux
cadre jambes + fond decale 0 -1 + corps decale 0 -1 + tete decale -1 -1 + yeux decale -1 -1

# Elle plonge de son perchoir, griffes en avant.
anim attaque 100
cadre jambes + fond decale -1 0 + corps decale -1 0 + tete decale -2 0 + yeux decale -2 0 duree 170
cadre jambes-a + fond + corps + tete decale 2 1 + yeux decale 2 1
cadre jambes-a + fond decale 1 0 + corps decale 1 0 + tete decale 3 1 + yeux decale 3 1 duree 140
cadre jambes + fond + corps + tete + yeux

anim blesse 120
cadre jambes + fond decale -1 0 + corps decale -1 0 + tete decale -2 1 + yeux decale -2 1
cadre jambes + fond + corps + tete decale -1 0 + yeux decale -1 0

# Elle se brise en éclats de pierre.
anim mort 160
cadre jambes + fond decale -1 2 + corps decale -1 2 + tete decale -3 3 + yeux decale -3 3
cadre jambes-b decale 0 3 + fond decale 0 5 + corps decale 0 5 + tete decale -2 7 + yeux decale -2 7
cadre tas duree 900

sprite gargouille-elite
modele gargouille
sombre
